# Звуковые движки и управление

Справочник по инструментам PurrMidi: список движков, выбор программы, управление с MIDI-клавиатуры и устройство каждого
движка. Краткая инструкция по работе с прибором — в [README](../README_RU.md), внутреннее устройство прошивки — в
[ARCHITECTURE.md](ARCHITECTURE.md), банк SoundFont — в [SOUNDFONT.md](SOUNDFONT.md).

## Список движков

Одновременно звучит один движок. Один и тот же код работает в прошивке и в Windows-приложении.

| Программа | Инструмент | Голоса | Описание | Исходники (`Engine/synth/`) |
| --------: | ---------- | -----: | -------- | --------------------------- |
| `0` | **E-Piano** | 8 | FM-электропиано в духе Rhodes / DX7 (по умолчанию) | `epiano_synth.cpp` |
| `1` | **Pluck** | 8 | Нейлоновая гитарная струна (Карплус — Стронг + корпус) | `pluck_synth.cpp` |
| `2` | **Lead** | 8 | Аналоговый субтрактивный лид на DaisySP (`Oscillator`, `Svf`, `Adsr`) | `lead_synth.cpp` |
| `3` | **Organ** | 12 | Тонколесный орган на `bfreeOrgan2`, drawbars и хорус | `organ_synth.cpp` |
| `4` | **Violin** | 8 | Физическая модель смычковой струны (волновод, как STK `Bowed`) и резонансы деки | `violin_synth.cpp` |
| `5…` | **SoundFont** | до 32 | SoundFont2 на TinySoundFont: каждый пресет банка — отдельная программа | `soundfont_synth.cpp` |

## Выбор инструмента (Program Change)

Нумерация значения Program Change (`data1`) начинается с нуля. Некоторые клавиатуры показывают номера с единицы, тогда `127`
отображается как №128. На дисплее номер тоже показан с единицы (программа `0` → «01»).

Всего программ `5 + N`, где `N` — число пресетов в загруженном SF2. Если банка нет, `N` считается равным 1: под номером `5`
остаётся программа «SoundFont», выбор которой сообщает об ошибке. Число программ возвращает `SynthEngine_GetProgramCount()`.

| `data1` | Действие |
| ------: | -------- |
| `0…4` | Выбрать E-Piano, Pluck, Lead, Organ, Violin |
| `5…(5+N−1)` | Выбрать SoundFont и его пресет №(`data1` − 5) |
| до `126` | Номера за пределами списка: `program % (5 + N)` |
| **`127`** | **Следующая программа по кругу** (Next Instrument) |

Порядок цикла `127`: E-Piano → Pluck → Lead → Organ → Violin → SF: пресет 1 → … → SF: пресет N → E-Piano.
Недоступные движки (например, SoundFont без банка) пропускаются. Напрямую выбрать программу `127` нельзя.

Правила переключения:

* Канал не учитывается (omni).
* Повторный выбор активного инструмента состояние не сбрасывает. Смена пресета SoundFont внутри активного движка не обрывает
  звучащие ноты: они доигрывают прежним тембром, новые берут новый пресет. Выбранный пресет сохраняется при `Panic` и при
  переключении на другой инструмент и обратно.
* При смене инструмента новый движок стартует с чистого состояния; возможна короткая пауза тишины.
* **Кнопка K1 (PC13)** на плате работает как Program Change `127`, с неблокирующим debounce.
  Если ваш контроллер умеет отправлять Program Change, назначьте `127` на любую кнопку (например, SUS).
* **Сохранение.** На STM32 выбор программы и громкость сохраняются в резервных регистрах RTC (`Platform/system/backup.c`) и
  восстанавливаются после перезапуска. После отключения питания они остаются только при установленной батарейке на VBAT
  (см. [HARDWARE.md](HARDWARE.md#батарейка-vbat-необязательно)). Без батарейки, а также при пустых или повреждённых данных
  запускается E-Piano (`SYNTH_ENGINE_DEFAULT` в `synth_engine.h`).
* В UART выводится строка `[PC] program N -> <имя>`.

## Общая громкость (CC7)

Громкость всего синтезатора задаётся Control Change **CC7** (канал не учитывается). У PCM5102A нет аппаратной регулировки, поэтому
`SynthEngine_FillStereoBuffer()` умножает выход активного движка на коэффициент.

* Кривая квадратичная: `127` → 1,0, `64` → ≈0,25 (−12 дБ), `0` → тишина.
* Коэффициент меняется плавно внутри блока, щелчков при вращении ручки нет.
* CC7 перехватывается в `SynthEngine_ControlChange()` и в движки не передаётся.
* Громкость не сбрасывается при смене инструмента; начальное значение — `SYNTH_MASTER_VOLUME_DEFAULT` (127).
* Макросы `SYNTH_MASTER_VOLUME_CC`, `SYNTH_MASTER_VOLUME_DEFAULT`; API: `SynthEngine_SetMasterVolume()` / `GetMasterVolume()`.

## Управление с клавиатуры

Педаль сустейна (CC64) работает на всех движках; CC7 — общая громкость; CC120 / CC123 (All Sound Off / All Notes Off) — на
E-Piano, Organ и SoundFont.

| Движок | Управление |
| ------ | ---------- |
| E-Piano | CC1, CC71, CC74 — яркость (индекс FM, `64` ≈ штатная); CC72 — время отпускания 0,08–1,7 с |
| Pluck | CC71, CC74 — яркость (`0` мягкий нейлон … `127` яркий); CC72 — длительность затухания; CC1 (мод-колесо) **добавляет** яркость, в нуле тембр не меняется |
| Lead | CC1 — глубина огибающей фильтра (0–10 кГц); CC74 — частота среза (30–12 000 Гц); CC71 — резонанс; CC73 — атака (0,002–1,5 с); CC72 — отпускание (0,02–2 с) |
| Organ | CC20–28 — drawbars (16′ … 1′); CC70 — хорус вкл/выкл; CC71 / CC72 — скорость / глубина хоруса; CC77 / CC78 — атака / отпускание |
| Violin | CC1 — вибрато; CC2 / CC11 — экспрессия; CC70 — положение смычка; CC71 — прижим; CC72 / CC73 — отпускание / атака; CC74 — яркость; CC75 — шум смычка |
| SoundFont | Pitch Bend по RPN 0 (по умолчанию ±2 полутона); отдельных CC нет |

**Pitch Bend**: E-Piano и Violin (±2 полутона), SoundFont. **Channel Pressure (aftertouch)**: только Violin (усиливает
смычок). Polyphonic Key Pressure доходит до движка, но пока не используется ни одним. Остальные движки Pitch Bend и aftertouch
игнорируют. Velocity меняет громкость, а у E-Piano, Pluck и Violin ещё и тембр.

## E-Piano

FM-синтезатор в духе Rhodes / Yamaha DX7 «E.PIANO 1». Звучит по умолчанию после включения. Все операторы — синусоиды
(таблица 2048 точек, линейная интерполяция), частота ноты `f`:

| Пара | Модулятор → несущая | Роль |
|---|---|---|
| BODY | `1·f → 1·f` | тело звука; индекс растёт с velocity и затухает («лай» при сильном ударе мягчеет) |
| TINE | `14·f → 1·f` | «звон» молоточка, T60 ≈ 0,3 с; отключается плавно, когда `14·f` приближается к 18 кГц (защита от алиасинга) |

`voice = amp_env · velocity_gain · (BODY + tine_level · TINE)`. Индексы модуляции пропорциональны `velocity²`, громкость
~ `velocity^1,5`; к верхним нотам индекс убывает, басы звучат дольше (T60 от ~18 с на C2 до ~4,5 с на C6). После отпускания клавиши
T60 = 0,25 с (CC72), при педали нота затухает по «удерживаемой» огибающей. Повторная нота переиспользует свой голос; при нехватке
голосов крадётся самый тихий отпущенный, затем самый старый (атака 2 мс, без щелчков). Лёгкая панорама по положению клавиши
(`EPIANO_STEREO_SPREAD`, 0 = моно), уровень — `EPIANO_MASTER_GAIN` и мягкий лимитер.

Константы тембра — в начале `epiano_synth.cpp` (`EPIANO_TINE_RATIO`, `EPIANO_BARK_T60_SEC`, `EPIANO_TINE_T60_SEC`,
`EPIANO_MASTER_GAIN`), индексы модуляции — в `start_voice()`. Размер для Cortex-M7: около 3 КБ кода и 9 КБ RAM.

## Pluck

Собственная модель Карплуса — Стронга с корпусом классической гитары. Выход моно, дублируется в оба канала.

```text
шум → два ФНЧ → гребёнка положения щипка → убрать DC → нормировка RMS
                           │ (заполняет линию задержки при Note On)
                           ▼
        ┌────────── линия задержки (2048 сэмплов) ◄───────────┐
        ▼                                                      │
   all-pass (дробная часть задержки) → ФНЧ потерь → усиление g ┘
                           │
                     демпфер (release)
                           ▼
        сумма голосов → корпус → мягкий ограничитель → int16
```

* **Возбуждение.** Шум (xorshift32 со сбросом в `PluckSynth_Init()`, звук воспроизводим бит-в-бит) проходит два ФНЧ со срезом
  `500 + 3000·яркость + 1500·velocity` Гц, затем гребёнку `e[j] −= e[j − P]`, `P = 0,17·длина` (подавляет гармоники, кратные
  положению щипка). Уровень нормируется по RMS, поэтому при одной velocity все ноты одинаково громкие.
* **Петля.** `g` подбирается так, чтобы основной тон падал на 60 дБ за T60, а ФНЧ потерь гасит обертоны быстрее. На C4
  `T60 = 5·decay − 1,3` с (ограничено 0,15–3,7 с, по умолчанию `decay = 0,88`, около 3,1 с); для другой высоты умножается на
  `(261,63 / f)^0,35`. Настройка (задержка) считается один раз при Note On.
* **Корпус.** Три общих резонатора на 98 Гц (воздух), 205 Гц (верхняя дека) и 410 Гц.
* **Выход.** Нормировка `1/(1+0,4·(N−1))`, `PLUCK_OUTPUT_GAIN` (1,9), `synth::SoftLimit` (колено 0,85, потолок 0,99).
  После Note Off демпфер гасит струну за 0,2 с (`PLUCK_RELEASE_TIME_SEC`).

Параметры по умолчанию (`pluck_synth.cpp`): `PLUCK_BRIGHT_DEFAULT` 0,40, `PLUCK_DECAY_DEFAULT` 0,88, `PLUCK_PICK_POSITION` 0,17,
`PLUCK_EXCITE_RMS` 0,30. Яркость из CC71/74: `0,10 + значение·0,90`; CC1 даёт `яркость + (1 − яркость)·колесо`; CC72:
`0,50 + значение·0,495`. API: `PluckSynth_SetDecay(0…1)`, `PluckSynth_SetDamp(0…1)` (Damp = яркость).

Ограничения: если менять яркость во время ноты, высота плывёт на несколько центов; минимальная частота около 23,5 Гц; корпус
моделируется тремя резонансами, а не импульсным откликом настоящей гитары.

## Lead

Полифонический субтрактивный синтезатор: осциллятор и фильтр `Svf` из DaisySP, огибающие `Adsr`. Параметры управляются CC
(см. таблицу выше), CC1 задаёт глубину огибающей фильтра.

## Organ

Адаптер `organ_synth.cpp` над библиотекой `bfreeOrgan2` (`Middlewares/Third_Party/bfreeOrgan2/`, сама библиотека не менялась).
Библиотека рассчитана на большой запас по уровню, поэтому в адаптере добавлено усиление `ORGAN_OUTPUT_GAIN` (×3,5, около +11 дБ)
и мягкий ограничитель `synth::SoftLimit` (колено 0,80, потолок 0,98), как у Lead и Violin. Громкость органа выровнена с остальными
движками по одному и тому же аккорду C–E–G; для коррекции меняется одна константа.

На плотных аккордах фиксированное усиление ×3,5 выводило пик за колено ограничителя и давало хрип. Поэтому усиление ведёт
медленный регулятор `synth::AutoGain` (`synth_common.h`): на 1–3 нотах остаётся ×3,5, на плотных аккордах плавно снижается так,
чтобы пик блока не превышал колено (быстрое снижение за 32 отсчёта, возврат с постоянной времени 0,25 с, `ORGAN_AGC_RELEASE`).
Форма волны не искажается, `SoftLimit` остаётся страховкой. Цена: громкость аккорда перестаёт расти выше примерно −11 дБFS
(RMS), уже звучащие ноты слегка «приседают» при добавлении новых.

## Violin

Физическая модель смычковой струны (волновод + нелинейное трение смычка, как в STK `Bowed`), резонансы деки, 8 голосов.
Управление — в таблице выше; Pitch Bend (±2 полутона) и aftertouch (усиливает смычок) поддерживаются.

## SoundFont

Синтезатор SoundFont2 на базе TinySoundFont. Сэмплы читаются прямо из QSPI Flash (XIP), банк обновляется с SD-карты при
запуске. На дисплее показывается «SF:имя пресета». Подробности — в [SOUNDFONT.md](SOUNDFONT.md).

## Общий программный интерфейс

* `SynthEngine_Init()` — запуск движка по умолчанию.
* `SynthEngine_NoteOn()`, `SynthEngine_NoteOff()`, `SynthEngine_ControlChange()`.
* `SynthEngine_ProgramChange()` — выбор по номеру программы; `SynthEngine_Select()` — по идентификатору движка;
  `SynthEngine_GetCurrent()`.
* `SynthEngine_FillStereoBuffer()` — заполнение стереобуфера.

`SynthEngine` сам выбор не сохраняет, это делает `main.c`. Вызовы управления идут из основного цикла или MIDI-контекста, а
заполнение буфера — из аудиопрерывания (STM32) или аудиопотока (ПК).

## Тесты

Для каждого движка есть хостовой тест `tests/test_<движок>_host.cpp`; `test_queue_dispatch` проверяет цепочку «очередь →
диспетчер → синтезатор», `test_synth_switch` — переключение по Program Change, `test_engine_golden` — бит-в-бит одинаковый
результат при повторных прогонах с переключением движков. Запуск — в [WINDOWS_BUILD.md](WINDOWS_BUILD.md#прогон-тестов).
