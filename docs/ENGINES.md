# Звуковые движки и управление

Подробности о движках, переключении инструментов, общей громкости и программном интерфейсе. Краткая справка по работе с прибором — в [README](../README_RU.md); устройство внутри — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Список движков

Все шесть движков входят в архитектуру прошивки и Windows-сборки. Активный инструмент выбирается во время работы по MIDI Program Change.

| Номер программы | Инструмент    | Описание                                                                                                                                                                                                                                  |
| --------------: | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|             `0` | **E-Piano**   | Полифоническое FM-электропиано, до 8 голосов. `Engine/synth/epiano_synth.cpp`. Подробнее: `docs/EPIANO_SYNTH.md`. |
|             `1` | **Pluck**     | Нейлоновая гитарная струна: собственная модель Карплуса — Стронга с корпусом классической гитары, до 8 голосов. `Engine/synth/pluck_synth.cpp`. Подробнее: `docs/PLUCK_SYNTH.md`. |
|             `2` | **Lead**      | Полифонический аналоговый субтрактивный синтезатор лидов на базе DaisySP (`Oscillator`, `Svf`, `Adsr`). `Engine/synth/lead_synth.cpp`. |
|             `3` | **Organ**     | Тонколесный орган на базе `bfreeOrgan2`. `Engine/synth/organ_synth.cpp`, `Middlewares/Third_Party/bfreeOrgan2/`. Поддерживает регистровые рукоятки (drawbars) и хорус. Громкость выровнена с остальными движками (см. ниже). |

|        `5…`     | **SoundFont** | Синтезатор SoundFont2 на базе TinySoundFont, **последний в списке**. Читает сэмплы из QSPI Flash (XIP) с автообновлением с SD-карты (`0:/SNDFNT.SF2`). Подробнее: `docs/SOUNDFONT_QSPI_SYNTH.md`. |

### Pluck: управление с клавиатуры

| MIDI CC | Действие |
| ------: | -------- |
| `1` (мод-колесо) | Добавляет яркость к текущей: в нуле (колесо отпущено) тембр не меняется, вверх звук светлеет к «стальной» струне. Длительность ноты колесо не меняет |
| `71`, `74` | Яркость (абсолютная): `0` — самый мягкий нейлон, `127` — самый яркий |
| `72` | Длительность затухания струны |
| `64` | Педаль сустейна |

Velocity меняет и громкость, и яркость щипка (сильный удар светлее). Модель струны, значения всех констант и результаты измерений — в [PLUCK_SYNTH.md](PLUCK_SYNTH.md).

### Organ: уровень громкости

Библиотека `bfreeOrgan2` рассчитана на большой запас по уровню, поэтому орган звучал на 8–10 дБ тише остальных движков. В адаптере `Engine/synth/organ_synth.cpp` добавлено усиление `ORGAN_OUTPUT_GAIN` (×3,5, около +11 дБ) и мягкий ограничитель `synth::SoftLimit` (колено 0,80, потолок 0,98 от полной шкалы — те же, что у Lead и Violin). Сама библиотека не менялась. Если орган понадобится сделать тише или громче, меняется одна константа.

Усиление ×3,5 подобрано под одну-три ноты: на трёх нотах пик на выходе уже около 0,79 от полной шкалы. На шести и более нотах он заходил за колено, и статическая кривая `SoftLimit` сплющивала вершины каждого периода: это слышно как хрип (на шести нотах 7% отсчётов лежали в нелинейной зоне, на восьми — 18%, на десяти — 33%). Поэтому усиление теперь делает медленный регулятор `synth::AutoGain` (`Engine/synth/synth_common.h`): на 1–3 нотах оно остаётся ×3,5 (звук бит в бит прежний), а на плотных аккордах плавно снижается так, чтобы пик блока не превышал колено. Усиление меняется одинаково для всех отсчётов блока и медленно (быстрое снижение за 32 отсчёта, возврат с постоянной времени 0,25 с, `ORGAN_AGC_RELEASE`), поэтому форма волны не искажается; `SoftLimit` остаётся страховкой. Цена: громкость аккорда перестаёт расти выше уровня около −11 дБFS (RMS) вместо насыщения; при добавлении нот уже звучащие слегка «приседают» по громкости, как у любого лимитера.

Выравнивание проверялось одним и тем же аккордом C–E–G, velocity 100, по RMS в окне 0,1–0,6 с (разовое измерение, в автотесты не входит):

| Движок | Аккорд, RMS, дБFS |
| ------ | -----------------: |
| E-Piano | −10,8 |
| Lead | −14,8 |
| Violin | −14,0 |
| Pluck (после правки) | −17,1 (звук затухающий, пик около −0,1) |
| Organ было / стало | −23,1 / −12,3 |

### Поведение MIDI Program Change

В обработчике MIDI используется **нулевая нумерация** значения Program Change (`data1`). Некоторые MIDI-клавиатуры и программы показывают номера программ с единицы, поэтому значение `data1 = 127` может отображаться в интерфейсе как программа №128. На дисплее номер показывается с единицы (программа `0` → «01»).

Всего программ: `5 + N`, где `N` — число пресетов в загруженном SF2 (если банка нет, `N` считается равным 1: под номером `5` остаётся одна программа «SoundFont», выбор которой сообщает об ошибке). Общее число возвращает `SynthEngine_GetProgramCount()`.

| Значение `data1` | Поведение                                                    |
| ---------------: | ------------------------------------------------------------ |
|              `0` | Выбрать E-Piano                                              |
|              `1` | Выбрать Pluck                                                |
|              `2` | Выбрать Lead                                                 |
|              `3` | Выбрать Organ                                                |
|              `4` | Выбрать Violin                                               |
|     `5…(5+N−1)` | Выбрать SoundFont и его пресет №(`data1` − 5)                |
|      до `126`  | Номера за пределами списка: `program % (5 + N)`              |
|        **`127`** | **Переключиться на следующую программу**                     |

Значение `127` зарезервировано как команда **Next Instrument**. Оно не проходит через обычное сопоставление номера программы по модулю (поэтому напрямую выбрать программу `127` нельзя; до неё можно дойти циклом `127`). При каждом таком сообщении программа меняется на следующую в последовательности:

```text
E-Piano → Pluck → Lead → Organ → Violin → SF:пресет 1 → SF:пресет 2 → … → SF:пресет N
    ↑                                                                                              │
    └──────────────────────────────────────────────────────────────────────────────────────────────┘
```

Если банк SoundFont недоступен, SoundFont и все его пресеты автоматически пропускаются в цикле.

Другие правила переключения:

* Номера программ `0–4` напрямую выбирают встроенные инструменты, начиная с `5` — пресеты SoundFont.
* Для номеров за пределами списка используется циклическое сопоставление по модулю числа программ.
* MIDI-канал Program Change не учитывается: переключение работает в режиме omni.
* При повторном выборе уже активного инструмента состояние движка не сбрасывается. Смена пресета SoundFont внутри уже активного движка не обрывает звучащие ноты: они доигрывают прежним тембром, новые берут новый пресет. Выбранный пресет сохраняется при `Panic` и при переключении на другой инструмент и обратно.
* При смене инструмента новый движок инициализируется с чистого состояния. Переключение может сопровождаться кратковременной выдачей тишины, чтобы не блокировать аудиопрерывание.
* На STM32 выбор инструмента и громкость сохраняются в резервных регистрах RTC (`Platform/system/backup.c`) и переживают перезагрузку; при выключении питания - только если на вывод VBAT подключена батарейка (WeAct: разъём P2, пин 6 `VB`, CR2032 между `VB` и GND). Без батарейки, а также при пустых или повреждённых данных запускается E-Piano; значение задаётся `SYNTH_ENGINE_DEFAULT` в `Engine/synth/synth_engine.h`.
* Переключение может выводиться в UART в формате `[PC] program N -> <имя>`; Windows-приложение также выводит диагностические сообщения в консоль.

Для кнопки, назначенной на переключение следующего инструмента, следует использовать MIDI Program Change со значением `127`. Например, это позволяет использовать кнопку SUS контроллера для последовательного перебора звуков, если контроллер можно настроить на отправку такого сообщения.

Кроме того, циклический перебор доступных инструментов можно выполнять встроенной кнопкой **User Key K1 (PC13)** на плате. Одно нажатие K1 приводит к переключению на следующий доступный инструмент (как MIDI Program Change `127`), использует ту же логику пропуска недоступных движков, обрабатывается в основном цикле с неблокирующим программным debounce и обновляет отображение инструмента на дисплее.

### Общая громкость (MIDI CC7)

Громкость всего синтезатора регулируется с MIDI-клавиатуры сообщением Control Change **CC7** (Channel Volume) — его обычно шлют ползунок или ручка громкости. Канал не учитывается.

У PCM5102A нет аппаратной регулировки громкости (у него нет ни I2C, ни SPI; из управляющих выводов только FLT, DEMP, XSMT и FMT), поэтому громкость меняется программно: `SynthEngine_FillStereoBuffer()` умножает выходные отсчёты активного движка на коэффициент. Это работает одинаково для всех восьми движков и не сбрасывается при смене инструмента.

* Кривая квадратичная: `127` → 1.0 (без ослабления), `64` → ≈0.25 (−12 дБ), `0` → тишина.
* Коэффициент меняется плавно внутри блока, поэтому щелчков при вращении ручки нет.
* После включения питания громкость равна `127` (как до появления регулировки).
* CC7 перехватывается в `SynthEngine_ControlChange()` и в движки не передаётся (иначе громкость применялась бы дважды).
* Номер контроллера и стартовый уровень переопределяются макросами `SYNTH_MASTER_VOLUME_CC` и `SYNTH_MASTER_VOLUME_DEFAULT` (`Engine/synth/synth_engine.h`).
* Программный доступ: `SynthEngine_SetMasterVolume()` и `SynthEngine_GetMasterVolume()`.

### Общий интерфейс движков

Основные функции общего API:

* `SynthEngine_Init()` — запуск движка по умолчанию.
* `SynthEngine_NoteOn()` и `SynthEngine_NoteOff()` — обработка нот.
* `SynthEngine_ControlChange()` — передача MIDI Control Change.
* `SynthEngine_ProgramChange()` — выбор инструмента по номеру программы.
* `SynthEngine_Select()` — явный выбор движка по идентификатору.
* `SynthEngine_GetCurrent()` — получение текущего инструмента.
* `SynthEngine_FillStereoBuffer()` — заполнение стереобуфера.

Сам `SynthEngine` выбор не сохраняет (это делает `main.c`, см. выше). Вызовы управления выполняются из основного цикла или MIDI-контекста, а заполнение аудиобуфера — из аудиопрерывания на STM32 либо аудиопотока на ПК.
