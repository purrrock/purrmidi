# Pluck: нейлоновая гитарная струна

Движок Pluck (Program Change `1`) моделирует щипок нейлоновой струны классической гитары. Реализация — `Engine/synth/pluck_synth.cpp`, интерфейс — `Engine/synth/pluck_synth.h`. До 8 голосов (`PLUCK_VOICES`), частота дискретизации 48 кГц, выход моно, дублируется в оба канала.

Краткая справка по управлению — в [ENGINES.md](ENGINES.md).

## Почему раньше звук был металлическим

Прежняя версия использовала DaisySP `Pluck`. Он проигрывает буфер белого шума с шагом, зависящим от высоты ноты, то есть прореживает его с алиасингом, а потери в петле применяет один раз за проход по всему буферу. В результате верхние гармоники почти не затухают, и струна звенит, как стальная. Измерение (A3, velocity 100, параметры по умолчанию): спектральный центроид в первые 0,2 с около 3,7 кГц и около 3,2 кГц на 0,5–0,7 с.

## Как устроен голос

```text
шум → два ФНЧ → гребёнка положения щипка → убрать DC → нормировка RMS
                                   │
                                   ▼ (заполняет линию задержки при Note On)
        ┌──────────── линия задержки (2048 сэмплов) ◄──────────┐
        ▼                                                       │
   all-pass (дробная часть задержки) → ФНЧ потерь → усиление g ─┘
                                   │
                             демпфер (release)
                                   ▼
                    сумма голосов → корпус → мягкий ограничитель → int16
```

1. **Возбуждение** (`excite()`). Шум (генератор xorshift32 со сбросом в `PluckSynth_Init()`, поэтому звук воспроизводим бит-в-бит) проходит два однополюсных ФНЧ: подушечка пальца и нейлон дают мягкий щипок. Частота среза: `500 + 3000·яркость + 1500·velocity` Гц. Затем гребёнка `e[j] −= e[j − P]`, где `P = 0,17·длина`: так подавляются гармоники, кратные положению щипка, как у настоящей гитары. Постоянная составляющая убирается, уровень нормируется по RMS, поэтому все ноты одинаково громкие при одной velocity.
2. **Петля струны** (`process_voice()`). Линия задержки, all-pass для точной настройки (дробная часть задержки в диапазоне 0,5…1,5 сэмпла), однополюсный ФНЧ потерь и усиление `g < 1`. Задержка компенсирует фазовую задержку ФНЧ, настройка считается один раз при Note On.
3. **Затухание** (`update_loop()`). `g` выбирается так, чтобы основной тон падал на 60 дБ за время T60, а ФНЧ потерь заставляет обертоны затухать намного быстрее: звук «теплеет» уже через десятки миллисекунд. Оба параметра масштабируются по высоте ноты (на высоких нотах проходов за секунду больше, поэтому потери на проход меньше, а T60 короче).
4. **Корпус** (`body_process()`). Три параллельных резонатора (полосовые фильтры): 98 Гц (воздушный резонанс), 205 Гц (верхняя дека), 410 Гц. Общие на все голоса. Когда все голоса замолчали, резонаторы дозваливают и обнуляются, чтобы тишина была точной.
5. **Выход.** Нормировка по числу голосов `1/(1+0,4·(N−1))`, усиление `PLUCK_OUTPUT_GAIN`, мягкий ограничитель `synth::SoftLimit` (колено 0,85, потолок 0,99).

После Note Off (при отпущенной педали) демпфер гасит струну с постоянной времени 0,2 с (`PLUCK_RELEASE_TIME_SEC`). Голос освобождается, когда сглаженный уровень падает ниже `1e-4`. Очередь событий, учёт нажатий, педаль CC64, вытеснение самого старого голоса и аварийное восстановление работают так же, как раньше (`synth_common.h`).

## Управление

| MIDI CC | Действие |
| ------: | -------- |
| `1` мод-колесо | Прибавка яркости: `яркость_эфф = яркость + (1 − яркость)·колесо`. В нуле ничего не меняется |
| `71`, `74` | Яркость (абсолютная): `0,10 + значение·0,90` |
| `72` | Затухание: `0,50 + значение·0,495` |
| `64` | Педаль сустейна |

Программный интерфейс: `PluckSynth_SetDecay(0…1)` и `PluckSynth_SetDamp(0…1)`; `Damp` теперь означает **яркость** (больше — ярче), на длительность основного тона он не влияет. Изменение контроллеров применяется и к уже звучащим голосам.

Время затухания основного тона (T60) на C4 при параметре `decay`: `T60 = 5·decay − 1,3` секунды (ограничено 0,15…3,7 с); по умолчанию `decay = 0,88`, то есть около 3,1 с. Для другой высоты умножается на `(261,63 / f)^0,35`.

### Исправление: мод-колесо

Раньше CC1 жёстко задавал демпфирование (`0,30 + значение·0,69`). В нуле, то есть когда колесо отпущено, получалось самое сильное демпфирование, и нота затухала примерно за 0,2 с (уровень около −47 дБFS против −22 дБFS у обычной ноты), как короткий удар по струне. Теперь CC1 только добавляет яркость, а длительность определяется усилением петли независимо от яркости.

## Настраиваемые константы (`pluck_synth.cpp`)

| Константа | Значение | Что делает |
| --------- | -------: | ---------- |
| `PLUCK_BRIGHT_DEFAULT` | 0,40 | Яркость по умолчанию |
| `PLUCK_DECAY_DEFAULT` | 0,88 | Затухание по умолчанию |
| `PLUCK_PICK_POSITION` | 0,17 | Положение щипка вдоль струны |
| `PLUCK_EXCITE_RMS` | 0,30 | Уровень возбуждения |
| `PLUCK_RELEASE_TIME_SEC` | 0,20 | Гашение после Note Off |
| `PLUCK_OUTPUT_GAIN` | 1,9 | Общее усиление |
| `body[]` | 98/205/410 Гц | Частота, добротность и вес резонаторов корпуса |

Яркость петли: коэффициент ФНЧ `c = (0,05 + 0,55·(1 − яркость))·(261,63/f)^0,8`, ограничен 0,02…0,62.

## Память и производительность

Голос занимает около 8,3 КБ (линия задержки 2048 float плюс состояние), восемь голосов — около 67 КБ в общей арене голосов, как и раньше. Расчёт на сэмпл у голоса: линейный, без циклов по буферу (старый DaisySP `Pluck` на каждом проходе обрабатывал буфер целиком). Корпус добавляет три бикварда на сэмпл всего выхода. Загрузка процессора на STM32 здесь не измерялась (проверялась только хостовая сборка и тесты): проверьте на приборе по счётчику `late=` в строке `[AUDIO]`.

## Ограничения

* Настройка (задержка) считается один раз при Note On. Если во время ноты менять яркость, ФНЧ петли меняет высоту на несколько центов, а не на полутона.
* Pitch Bend и aftertouch Pluck не использует.
* Минимальная частота струны около 23,5 Гц (длина линии 2048).
* Звук синтетический: корпус гитары моделируется тремя резонансами, а не импульсным откликом настоящего инструмента.
