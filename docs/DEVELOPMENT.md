# Состояние разработки

Что реализовано, как устроены тесты и CI и на каком этапе проект. Краткое описание — в [README](../README.md).

## Что уже реализовано

### Прошивка STM32H743

* Тактирование STM32H743VIT6: HSE 25 МГц, CPU 480 МГц, USB 48 МГц и тактирование аудио.
* Вывод стереозвука через SAI1 Block A, DMA2 Stream0 и PCM5102A: 48 кГц, 16 бит.
* USB MIDI Host с собственным классом `usbh_midi` поверх USB Host Library.
* Разбор USB-MIDI пакетов (`Engine/midi/usb_midi_packet.c`) с отсевом SysEx/Clock/Active Sensing и маскированием данных.
* MIDI-очередь на 256 событий с моделью SPSC (один производитель — один потребитель) и диспетчер MIDI-событий.
* Обработка Note On, Note Off, Control Change и Program Change.
* Единый диспетчер восьми звуковых движков.
* E-Piano с FM-синтезом и полифонией до 8 голосов.
* Pluck: нейлоновая гитарная струна (собственная модель Карплуса — Стронга, корпус гитары) с обработкой velocity, release, педали сустейна CC64 и параметров тембра.
* Organ на базе `bfreeOrgan2`: полифония, девять drawbars (CC20–28), хорус и управление огибающей.
* SoundFont2 на базе TinySoundFont с хранением банка во внешней QSPI Flash (8 МБ, режим XIP) и автоматическим прошиванием/обновлением с microSD-карты (`0:/SNDFNT.SF2`) при запуске. Банк хранится только во флеше; проигрывания напрямую с SD-карты нет.
* Настройка D-Cache: XIP-окно QSPI (read-only, write-through), AXI SRAM (write-back) для данных движков и кучи; DMA-буферы вынесены в non-cacheable D2 SRAM.
* Тестовый синусоидальный движок для диагностики аудиотракта.
* TFT ST7735: индикация подключения MIDI, активных нот, отображение прогресса загрузки/прошивки SoundFont и определение аккордов.
* Отладочный UART (USART3, 115200 8N1) и светодиод PE3, сигнализирующий о наличии нажатых нот.
* Исправление зависания энумерации USB-устройств описано в `docs/USB_Enumeration_fix.md`.
* Сброс звука при отключении USB-клавиатуры (нет «залипших» нот).
* Автоматический перезапуск после аппаратного сбоя (HardFault/MemManage/BusFault/UsageFault/NMI): отчёт о сбое уходит в UART, затем `NVIC_SystemReset()`. Для отладки по SWD соберите с `-DPURRMIDI_FAULT_HALT=1`, тогда после отчёта процессор останавливается.
* Контроль ошибок SAI (underrun/overrun) через прерывание SAI1.
* **Сторожевой таймер IWDG1** (`Platform/system/watchdog.c`): при загрузке таймаут ~8 с (обновление банка во флеше «кормит» таймер на каждом шаге), в работе ~1,5 с. Основной цикл «кормит» таймер только пока звук реально идёт (растёт счётчик блоков, обработанных PendSV), поэтому сбрасывается и зависший `main`, и остановившийся звук. Причина последнего сброса (IWDG, программный, питание...) печатается в UART строкой `[RESET] cause: ...`. Таймер замораживается при остановке ядра отладчиком. Модуль работает с регистрами и не зависит от HAL-модуля IWDG.
* Обнуление AXI SRAM и D2 SRAM 64-битными записями до конструкторов C++ (защита от ECC-ошибок на холодном старте).
* Рендер звука в PendSV (низкий приоритет), а не в прерывании DMA: USB и системный тик не блокируются на время расчёта блока.
* Общая арена памяти голосов и общий компонент `synth_common.h` для движков: RAM_D2 освобождена с 86% до 6%.

### Windows-приложение

В каталоге `Platform/windows/` находится приложение для проверки синтезаторов на ПК. Оно использует общий код движков и поддерживает MIDI-мониторинг, выбор MIDI-порта, настройку размера аудиобуфера, регулировку громкости и запись аудиовыхода в WAV.

Инструкции по сборке находятся в `docs/WINDOWS_BUILD.md`.

### Тесты и непрерывная интеграция

В `tests/` находятся хостовые тесты MIDI-декодера, разбора USB-MIDI пакетов прошивки, очереди событий, диспетчера, звуковых движков, переключения инструментов, SoundFont-загрузчика (включая эмуляцию QSPI NOR Flash) и детектора аккордов.

GitHub Actions (`.github/workflows/host-ci.yml`) выполняет:

* сборку и запуск хостовых тестов в Linux;
* сборку Windows-приложения `purrmidi_win.exe` с помощью MSVC.

В репозитории есть CMake-пресеты для прошивки (`Debug`, `Release`), хостовых тестов (`host-tests`) и Windows-сборок (`win-msvc-debug`, `win-msvc-release`, `win-mingw-release`).

**Этап 1 — аппаратный запуск**

* [x] Запуск MCU и базовая настройка тактирования STM32H743VIT6.
* [x] Вывод тестового тона через SAI/DMA и PCM5102A.
* [x] Настройка стереовывода с частотой 48 кГц.

**Этап 2 — базовый MIDI-синтезатор**

* [x] Очередь MIDI-событий и обработка Note On/Off.
* [x] Интеграция синтезатора с аудиобуфером и DMA.
* [x] Интеграция DaisySP Pluck и FM E-Piano.
* [x] Выбор движка через MIDI Program Change.
* [x] Стабилизация энумерации USB MIDI-клавиатур.

**Этап 3 — SoundFont, QSPI Flash и карта памяти**

* [x] Интеграция SDMMC1 и FatFs.
* [x] Интеграция QUADSPI и QSPI Flash W25Q64 (8 МБ) в режиме Memory-Mapped (XIP).
* [x] Автоматическая проверка, запись и обновление SF2-файла `0:/SNDFNT.SF2` с SD-карты во флеш-память при старте.
* [x] Настройка D-Cache для прямого сэмплирования из QSPI Flash без задержек.
* [x] SoundFont хранится только в QSPI Flash (XIP); SD-карта используется лишь для обновления банка при запуске (read-only), потоковый SD-кэш удалён.
* [x] Выбор SoundFont через Program Change (программы `5…`, по одной на каждый пресет банка).
* [x] Все пресеты загруженного SF2 доступны в списке программ, на дисплее «SF:имя».
* [x] Защита SoundFont от перегрузки: сброс денормалей (FPSCR.FZ) и ускоренное гашение отпущенных голосов при >75% бюджета блока.

**Этап 4 — расширение звуковых движков и хостовая разработка**

* [x] Добавление тонколесного органа на базе `bfreeOrgan2`.
* [x] Интеграция движков в общий интерфейс `SynthEngine`.
* [x] Переключение на следующий инструмент через Program Change `127`.
* [x] Windows-приложение для проверки звуковых движков.
* [x] Хостовые тесты и CI для Linux и Windows.

**Этап 5 — физическое моделирование**

* [x] Violin (волновод смычковой струны + резонансы деки). Dulcimer, Flute и Saxophone удалены.
* [x] Сброс звука при отключении клавиатуры, перезапуск после аппаратного сбоя, фильтрация системных USB-MIDI сообщений.
* [x] Из репозитория убраны все подмодули git (`DaisySP`, `MiniSTM32H7xx`, `eurorack`, `stk`, около 630 МБ при `--recursive`): нужные 7 файлов DaisySP и 4 файла драйвера ST7735 скопированы в проект. Прошивка при этом байт-в-байт та же.
* [x] Pluck переделан в нейлоновую струну (собственная модель вместо DaisySP `Pluck`); мод-колесо больше не укорачивает ноту. Громкость органа выровнена с остальными движками.

### Текущий статус

Основные компоненты аппаратного тракта и программной архитектуры интегрированы. Дальнейшее развитие проекта должно опираться на реальные результаты аппаратных испытаний, качество звучания, устойчивость работы при длительном воспроизведении и дальнейшее развитие звуковых движков.

Наличие хостовых тестов и успешной сборки само по себе не гарантирует безошибочную работу на физической плате. Аппаратная проверка USB-клавиатур, SD-карты, QSPI Flash, переключения инструментов и непрерывного аудиовывода остаётся важной частью проверки изменений.
