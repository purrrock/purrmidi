# Аппаратная часть: подключение и распиновка

Целевая плата: **WeAct STM32H743VIT6 Mini** (Cortex-M7) + модуль ЦАП **PCM5102A**.
Справочные материалы по плате (даташит, чертежи, распиновка WeAct) — в `docs/STM32H743VIT6/`,
исходный репозиторий WeAct: https://github.com/WeActStudio/MiniSTM32H7xx.

## Сводка выводов

| Назначение | Выводы |
|---|---|
| USB OTG FS (MIDI-клавиатура) | PA11 (D−), PA12 (D+); PA8, PA9, PA10 зарезервированы |
| Аудио, SAI1 Block A | PE4 (FS), PE5 (SCK), PE6 (SD) |
| Диагностический UART (USART3) | PB10 (TX), PB11 (RX) |
| Дисплей ST7735 (SPI4) | PE10 (BL), PE11 (CS), PE12 (SCK), PE13 (DC), PE14 (MOSI) |
| microSD (SDMMC1) | PC8–PC12, PD2 |
| QSPI Flash 8 МБ  (банк SoundFont) | PB2, PB6, PD11, PD12, PD13, PE2 |
| Кнопка K1 | PC13 |
| Светодиод DEBUG_LED | PE3 |
| SWD | PA13, PA14, NRST |

## USB MIDI Host

Интерфейс USB OTG FS, прибор работает как USB Host.

**Питание клавиатуры.** Плата не подаёт 5 В на VBUS разъёма, поэтому клавиатуре нужно внешнее питание. Если плата и клавиатура
питаются от одного USB-источника, используйте Y-разветвитель.

| Вывод | Сигнал | Провод USB |
|---|---|---|
| PA11 | USB_OTG_FS_DM | D−, белый |
| PA12 | USB_OTG_FS_DP | D+, зелёный |

## Аудио ЦАП PCM5102A

Интерфейс SAI1 Block A, MCLK не используется (ЦАП работает по трём линиям, SCK ЦАПа замкнут на землю перемычкой, см. ниже).

| Вывод STM32 | Сигнал SAI | Вывод PCM5102A |
|---|---|---|
| PE6 | SAI1_SD_A | DIN |
| PE5 | SAI1_SCK_A | BCK |
| PE4 | SAI1_FS_A | LCK / LRCK |
| GND | — | GND |
| 3,3 В | — | VIN: питание модуля (модуль допускает 3,3 или 5 В, в PurrMidi используется 3,3 В) |
| — | — | выходы L / R: усилитель или наушники |

### Перемычки на плате PCM5102A

Распространённый фиолетовый модуль (фото: [`docs/PCM5102.webp`](PCM5102.webp)) без пайки перемычек не работает: уходит в Mute
или искажает звук из-за неверного формата данных. На обороте платы четыре группы контактов **H1L–H4L**: центральная площадка
связана с ножкой микросхемы, боковые — с высоким (H, 3,3 В) или низким (L, GND) уровнем. Нужная конфигурация:

| Группа | Ножка | Замкнуть на | Что даёт |
|---|---|---|---|
| H1L | FLT | **L** | обычный FIR-фильтр |
| H2L | DEMP | **L** | деэмфазис выключен |
| H3L | XSMT | **H** | выход из Mute (без этого звука нет) |
| H4L | FMT | **L** | формат I2S (при H будет громкий шум) |

На лицевой стороне, у надписи SCK, есть ещё одна перемычка: она замыкает вход SCK на GND, и ЦАП сам получает системный такт из BCK.
Её нужно запаять, так как MCLK у STM32 не выводится.

## Диагностический UART

`115200, 8N1`. Загрузка, состояние USB/MIDI, синтезатора и SD/QSPI. Подключение к USB-UART адаптеру:

| Вывод STM32 | Сигнал | Адаптер |
|---|---|---|
| PB10 | USART3_TX | RX (белый) |
| PB11 | USART3_RX | TX (зелёный) |
| GND | GND | GND (чёрный) |

## Дисплей ST7735

TFT 160×80 на плате WeAct, SPI4 (только передача, Simplex Bidirectional Master). Показывает статус MIDI, активные ноты, название
аккорда и выбранный инструмент.

| Вывод | Сигнал | Назначение |
|---|---|---|
| PE12 | SPI4_SCK | LCD_SCL |
| PE14 | SPI4_MOSI | LCD_SDA |
| PE11 | GPIO | LCD_CS (программный) |
| PE13 | GPIO | LCD_DC (команда/данные) |
| PE10 | GPIO | LCD_BL (подсветка, **включается низким уровнем**) |

## Кнопка K1 и светодиод

* **K1 (PC13)** — User Key на плате: следующий инструмент (как Program Change `127`).
* **PE3, DEBUG_LED** — горит, пока удерживается хотя бы одна нота.

## microSD (SDMMC1)

Слот на плате WeAct, 4-битный режим. Карта нужна только при запуске, для обновления банка SoundFont
(см. [SOUNDFONT.md](SOUNDFONT.md)).

| Вывод | Сигнал SDMMC1 | Линия карты |
|---|---|---|
| PC8 | D0 | DAT0 |
| PC9 | D1 | DAT1 |
| PC10 | D2 | DAT2 |
| PC11 | D3 | DAT3 / CD |
| PC12 | CK | CLK |
| PD2 | CMD | CMD |

Линия датчика карты PD4 не используется. На D0–D3 и CMD нужны подтяжки к питанию, скорость выводов `Very High`.

## QSPI Flash (банк SoundFont, XIP)

Микросхема Winbond W25Q64 (8 МБ) распаяна на плате WeAct и подключена к QUADSPI Bank1. Выводы фиксированы разводкой платы:

| Вывод | Сигнал | AF |
|---|---|---|
| PB2 | QUADSPI_CLK | AF9 |
| PB6 | QUADSPI_BK1_NCS | AF10 |
| PD11 | QUADSPI_BK1_IO0 | AF9 |
| PD12 | QUADSPI_BK1_IO1 | AF9 |
| PE2 | QUADSPI_BK1_IO2 | AF9 |
| PD13 | QUADSPI_BK1_IO3 | AF9 |

**IO3 — только PD13.** CubeMX может по умолчанию назначить `QUADSPI_BK1_IO3` на PA1, но на плате WeAct линия IO3 флеша
заведена на PD13. С PA1 флеш не определится (JEDEC ID `00 00 00` или `FF FF FF`). Скорость всех шести выводов — `Very High`
(по умолчанию CubeMX ставит Low, и на 80–120 МГц это даёт ошибки чтения). Параметры QUADSPI и SDMMC1 в CubeMX —
в [SOUNDFONT.md](SOUNDFONT.md#настройка-cubemx).

## Батарейка VBAT (необязательно)

Выбор инструмента и громкость хранятся в резервных регистрах RTC. Без батарейки они переживают сброс, но не отключение питания.
Чтобы настройки сохранялись при выключении, поставьте 3V батарейку (например, CR2032) между выводом `VB` плюс батарейки (разъём P2, пин 6) и GND. Без батарейки после
включения питания запускается E-Piano с полной громкостью.

## SWD

Порт отладки должен оставаться доступным для прошивки: PA13 (SWDIO), PA14 (SWCLK), NRST.
