# FM-электропиано (Program Change 0, по умолчанию)

Полифонический FM-синтезатор в духе Rhodes / Yamaha DX7 «E.PIANO 1». Файлы: `Engine/synth/epiano_synth.h`, `Engine/synth/epiano_synth.cpp`. Внешних зависимостей (DaisySP и т.п.) нет.

## Выбор инструмента

E-Piano — синтезатор по умолчанию: он звучит после включения питания. Из других инструментов на него можно вернуться сообщением MIDI **Program Change 0** (см. `Engine/synth/synth_engine.h`). Остальные программы: `1` — Pluck, `2` — Sine; номера `3…127` заворачиваются по модулю 3.

## Структура голоса

Все операторы — синусоиды (таблица 2048 точек + линейная интерполяция), частота ноты `f`:

| Пара | Модулятор → несущая | Роль |
|---|---|---|
| BODY | `1·f → 1·f` | тело звука; индекс модуляции растёт с velocity и затухает («лай» при сильном ударе мягчеет) |
| TINE | `14·f → 1·f` | высокочастотный «звон» молоточка/язычка; быстро затухает (T60 ≈ 0,3 с) |

`voice = amp_env · velocity_gain · (BODY + tine_level · TINE)`

Что учтено:
* **Динамика:** индексы модуляции пропорциональны `velocity²` — тембр, а не только громкость, зависит от силы удара; громкость ~ `velocity^1,5`.
* **Высота ноты:** индекс убывает к верхним нотам; «звон» плавно отключается, когда `14·f` приближается к 18 кГц (защита от алиасинга); басы звучат дольше (T60 удерживаемой ноты: ~18 с на C2 → ~4,5 с на C6).
* **Демпфер:** после отпускания клавиши затухание T60 = 0,25 с (меняется через CC72); при нажатой педали нота продолжает затухать по «удерживаемой» огибающей.
* **Голоса:** 8 (`EPIANO_NUM_VOICES`). Повторная нота реиспользует свой голос; при нехватке голосов крадётся самый тихий отпущенный, затем самый старый. Атака 2 мс и непрерывный уровень при краже — без щелчков.
* **Стерео:** лёгкая панорама по положению клавиши (`EPIANO_STEREO_SPREAD`, 0 = моно).
* **Уровень:** `EPIANO_MASTER_GAIN` + мягкий лимитер (без жёсткого клиппинга на плотных аккордах).

## MIDI

| Сообщение | Действие |
|---|---|
| Note On / Off (velocity 0 = Note Off) | запуск / отпускание голоса |
| CC64 | педаль сустейна |
| CC1, CC71, CC74 | яркость (индекс FM); 64 ≈ штатная |
| CC7 | громкость |
| CC72 | время релиза (0,08–1,7 с) |
| CC120 / CC123 | All Sound Off / All Notes Off |

Program Change обрабатывается диспетчером (`synth_engine`) и выбирает инструмент, а не параметры E-Piano. Pitch bend и aftertouch пока не обрабатываются (диспетчер их не передаёт).

## Потоки и память

События из основного цикла попадают в lock-free SPSC FIFO (64 события) и применяются в начале каждого `EPianoSynth_FillStereoBuffer()`; всё состояние голосов принадлежит аудиоконтексту, блокировок и динамической памяти нет. При переполнении FIFO события отбрасываются и учитываются в `EPianoSynth_GetDroppedEventCount()`. Размер для Cortex-M7: ≈3 КБ кода, ≈9 КБ RAM; нагрузка на CPU — порядка единиц процентов при 8 голосах на 480 МГц (оценка по числу операций, на железе не измерялась).

## Подстройка звука

Основные константы — в начале `epiano_synth.cpp`: `EPIANO_TINE_RATIO`, `EPIANO_BARK_T60_SEC`, `EPIANO_TINE_T60_SEC`, `EPIANO_MASTER_GAIN`; индексы модуляции и уровень «звона» — в `start_voice()`. Быстро послушать результат без железа: `purrmidi_win --play`, запись в WAV — ключ `--wav`.
