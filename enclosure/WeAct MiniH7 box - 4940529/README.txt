WeAct MiniH7 box by koendv on Thingiverse: https://www.thingiverse.com/thing:4940529

Summary:
The WeAct Mini H7 is a micropython board with camera and display that runs Open Machine Vision. This is a box for that board. I've added a small laser range finder, so I can detect if there is something in front of the camera.Prints without supports. Designed in OpenSCAD. You can download the OpenSCAD sources at github
