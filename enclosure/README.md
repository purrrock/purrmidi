# Корпус PurrMidi

Печатный корпус из двух деталей под WeAct STM32H743 Mini + модуль PCM5102A: `MiniSTM32H7xx_box_bottom_dac.stl`,
`MiniSTM32H7xx_box_top_dac.stl`. За основу взята модель [WeAct MiniH7 box by koendv](https://www.thingiverse.com/thing:4940529)
(оригинал с лицензией — в каталоге `WeAct MiniH7 box - 4940529/`).

## Расположение разъёмов

* Нижний торец: USB-C и microSD.
* Верхний торец: 3,5 мм.
* Верх: окно экрана, кнопка K1, два отверстия под светодиоды.

## Чертежи и модели

* `PCB_sizes.pdf` — размеры платы WeAct STM32H743 Mini.
* `PCM5102 board sizes.png` — размеры модуля ЦАП.
* `STM32H7xx CoreBoard WeAct Studio V12 3D.step` — 3D-модель платы.
