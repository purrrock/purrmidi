# Корпус PurrMidi (v0.1, черновик)

Печатный корпус из двух деталей под WeAct STM32H743 Mini + модуль PCM5102A.
Исходник: `purrmidi_case.scad` (OpenSCAD, параметрический).

## Расположение разъёмов
* Нижний торец: USB-C + microSD.
* Верхний торец: 3,5 мм.
* Верх: окно экрана, кнопка K1, два отверстия под светодиоды.

За образец взята модель WeAct MiniH7 box by koendv on Thingiverse: https://www.thingiverse.com/thing:4940529
