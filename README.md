# PurrMidi

**PurrMidi** — автономный MIDI-синтезатор на базе STM32: подключаете USB MIDI-клавиатуру, звук генерирует микроконтроллер и выводит его через внешний аудио ЦАП.

В проекте есть прошивка STM32H743, Windows-приложение для проверки звуковых движков на ПК (может работать без MIDI-клавиатуры), шесть звуковых движков (электропиано, нейлоновая струна, лид, орган, скрипка, SoundFont).
Проект развивается и пока не является законченным серийным продуктом.

## Аппаратное обеспечение

* **Микроконтроллер:** WeAct STM32H743VIT6 Mini (Cortex-M7).
* **Аудио ЦАП:** PCM5102A,.
* **MIDI-вход:** USB MIDI-клавиатура через USB OTG.
* **Кнопка управления:** User Key K1 на плате микроконтроллера для переключения инструмента.
* **Дисплей:** TFT ST7735 160×80 на плате — статус MIDI, активные ноты, название аккорда и выбранный инструмент.
* **Карта памяти:** microSD (FAT32). Используется **только при запуске**: для автоматической записи/обновления SoundFont-банка `0:/SNDFNT.SF2` во  Flash на плате. Во время игры SD-карта не нужна и не используется.

Физические подключения и распиновка описаны в `PINOUT.md`.

## Основы работы

**Подключение.** USB MIDI-клавиатуру подключите к USB OTG разъёму платы (прибор работает как USB Host), аудиовыход PCM5102A — к усилителю или наушникам. Включите питание: запускается E-Piano.
Если для питания платы используется тот же USB разъём, что и для подключения MIDI-клавиатуры (да, так можно!), то вам понадобится Y-разветвитель.

**Выбор инструмента.** Сообщением с MIDI-клавиатуры Program Change или кнопкой **K1** на плате.

| Program Change | Инструмент | Что это |
| -------------: | ---------- | ------- |
| `0` | **E-Piano** | FM-электропиано (по умолчанию) |
| `1` | **Pluck** | Нейлоновая гитарная струна |
| `2` | **Lead** | Аналоговый лид |
| `3` | **Organ** | Тонколесный орган |
| `4` | **Violin** | Скрипка |
| `5…` | **SoundFont** | Пресеты банка SoundFont2: `5` — первый, `6` — второй и т. д. |
| `127` | — | Следующий инструмент по кругу (так же работает K1) |

Название инструмента и активные ноты показываются на дисплее. Выбор не запоминается: после включения всегда E-Piano.

**Управление с клавиатуры.**

| Что | MIDI |
| --- | ---- |
| Общая громкость | CC7 (работает на всех инструментах) |
| Педаль сустейна | CC64 |
| Pluck: яркость / затухание | CC71, CC74 / CC72; мод-колесо (CC1) делает звук ярче, отпущенное колесо тембр не меняет |
| Organ: регистры, хорус | CC20–28 (drawbars), CC70 (хорус вкл/выкл), CC71/72 (скорость и глубина хоруса) |
| Violin: вибрато, смычок | CC1 вибрато, CC70/71/75 положение, прижим и шум смычка, Pitch Bend, aftertouch |
| E-Piano, Lead | см. [docs/EPIANO_SYNTH.md](docs/EPIANO_SYNTH.md), [docs/ENGINES.md](docs/ENGINES.md) |

**Свой SoundFont.** Положите файл банка в корень microSD-карты под именем `SNDFNT.SF2`, вставьте карту и включите прибор: банк автоматически запишется во флеш-память (30–60 секунд, ход виден на дисплее). Дальше карта не нужна. Подробности и диагностика — в [docs/SD_CARD_AND_QSPI.md](docs/SD_CARD_AND_QSPI.md).
Размер `SNDFNT.SF2` должен быть меньше 8МБ, иначе он не поместится во флеш-память. Вы можете попробовать уменьшить размер файла с помощью /SoundFonts/sf2_shrink.py или бесплатной утилитой Polyphone.
В каталоге /SoundFonts лежат несколько небольших бесплатных банков инструментов.

## Сборка

### Получение исходников

```bash
git clone https://github.com/purrrock/purrmidi
```

Всё, что нужно для сборки, лежит в самом репозитории (сторонний код — в `Middlewares/Third_Party/` и `Platform/display/st7735/`).

### Прошивка STM32

```bash
cmake --preset Debug
cmake --build --preset Debug
```

Для релизной сборки:

```bash
cmake --preset Release
cmake --build --preset Release
```

### Windows-версия

В Windows с установленным CMake и компилятором MSVC:

```bash
cmake --preset win-msvc-release
cmake --build --preset win-msvc-release
```

Инструкции и дополнительные сведения: `docs/WINDOWS_BUILD.md`.

Структура репозитория и список документов по подсистемам — в конце [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
