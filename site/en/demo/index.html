Try the sounds without hardware

This is the same sound-engine code as in the device, compiled to WebAssembly. Press “Turn sound on” and play with the mouse, your finger or the computer keyboard. Have a USB MIDI keyboard? Connect it to the browser.

MIDI keyboard

Computer keys

  • White keys: the home row A S D F G H J K L. The positions are physical, so any keyboard layout works.
  • Black keys: the row above, W E T Y U O P.
  • Z and X shift the octave; the space bar works as a sustain pedal.

A MIDI keyboard in the browser

Press “Connect a MIDI keyboard” and allow access. Notes, the pedal, the pitch wheel, CC knobs and Program Change (including 127, the next instrument) all work. Web MIDI is available in Chrome and Edge.

How the demo differs from the device

The engines are the same; the rest works differently in a browser.

The same

  • The code of all six engines from Engine/synth/, compiled to .wasm without changes.
  • 48 kHz, the same voices, knobs and default values.
  • Chord detection, as on the board's display.

Different

  • The sound goes through your computer's audio hardware, not the PCM5102A DAC. The latency depends on the browser and the system.
  • There is no SoundFont load governor, which on the board postpones some notes when it is overloaded.
  • A SoundFont bank in the demo can be larger than 8 MB; such a bank will not fit on the board.

Questions

There is no sound

Press “Turn sound on”: a browser does not start audio without an action from you. Check the volume and that the tab is not muted. On an iPhone, switch off silent mode with the side switch.

The sound lags behind my key presses

The browser and the sound card add latency. Try wired headphones and close tabs that load the processor heavily. In the device the sound goes from the microcontroller straight to the DAC through a small buffer (256 frames, about 5 ms), so its latency is lower.

My MIDI keyboard is not found

Plug the keyboard in before pressing the button or right after: the list updates by itself. If the browser showed no access prompt, use Chrome or Edge: Safari does not support Web MIDI. Another program may be holding the keyboard: close it.

How do I load my own SoundFont?

Pick the SoundFont instrument and press “or your own .sf2 file”. The file is not uploaded anywhere. If the bank is larger than 8,384,512 bytes, shrink it with the online tool so that it fits the device.
